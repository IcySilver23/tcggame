**Today.** A “holographic, silver, textured foil border” that Japan did not get, with “textured artwork” on the shiny cards. The treatment is documented outside Bulbapedia; the repeat is not. The finish is drawn as relief: these rarities now wear the granular sparkle surface; the documented silver border is still not modelled.

The only name collectors offer for the family is “Galaxy holo”, which Bulbapedia and folio.fyi both document as another name for Cosmos.

*Sources: reports/unnamed-finish.json · Bleeding Cool and PokéBeach, Paldean Fates set guide*

## 2. Claims this build refuses

### Black Bolt & White Flare — the 2025 Tinsel return (22 holo-rare rows)

**Today.** No foil claim. Bulbapedia’s Rarity page says Tinsel “returned as a once-off” there “with holofoil rare cards in these sets also having Tinsel Holofoil borders”, while its set page marks three poster-collection exclusives and TCGdex registers exactly those three. The sources disagree about which printings, the covered promos are not in this catalogue, and the one sentence about the holo rares describes a border — a different foil area from the striped image this build draws.

**Would close it.**

- A source naming which Black Bolt & White Flare printings carry Tinsel and where. If the foil is a border rather than the image, that is a different mask and needs its own geometry before it can be drawn; if it is the image, a card list that agrees with Bulbapedia’s set page reopens the 22 rows.
- Catalogue rows for the three poster-collection exclusives those sources name, since they are promos this catalogue does not carry today.

*Sources: reports/tinsel-printings.json · src/foil/tinsel-index.ts*

### McDonald’s Collections — 136 rows, one row per card

**Today.** Every McDonald’s row paints the Confetti foil, because each card exists in both a Non Holofoil and a Confetti Holofoil printing and the catalogue holds one row for the number. The finish and its product are verified; the limitation is the catalogue’s shape, not the source.

**Would close it.**

- Per-variant catalogue rows for the McDonald’s Collections — a source stating which copy is the Confetti one — then a variant gate like Sequin’s `sequinHolofoil`, so the plain printing makes no foil claim and the foil printing still does.

*Sources: reports/confetti-printings.json*

### POP Series holo versions with no named paper (3 cards)

### Victini (BW32) — in neither treatment catalogue

## 3. Evidence the painted sheets still lack

### Every drawn sheet is a reconstruction (7008 cards ride on them)

**Today.** No identified paper ships without a sheet, but no factory scan or angled photograph of a paper exists in this repository either: the sheets are drawn from a sentence, and each metadata file says so (10 reverse papers, the era papers and the promo papers alike).

**Would close it.**

- One tilted or macro photograph per paper, at a known angle and distance, catalogued so `textureVerified` can flip from false to true and the drawn pitch, density or ring size can be measured against it instead of disclosed.

*Sources: reports/unpainted-papers.json · reports/reverse-printings.json*

**Would close it.**

*Sources: reports/reverse-printings.json*
