# TCG Life

A collector-life simulator built on the **real** Pokémon Trading Card Game — real cards, real sets, real TCGplayer market prices, real card artwork. No invented cards. No invented prices.

![stack](https://img.shields.io/badge/stack-React%20%2B%20Hono%20%2B%20SQLite-blue)

## Quick start

```bash
npm install
npm run dev        # starts API (127.0.0.1:8787) + web UI (http://localhost:5199)
```

### Every clone starts from a clean save

No player's game is in the repository: `data/tcglife.db`, the `saves/` archives and
`release/` are gitignored, so a clone carries only the game itself. First boot
writes a brand-new save — $1,000, day 1, an empty collection — and seeds the full
20,898-card catalogue offline from the tracked `data/catalog-seed.db`, so playing
needs no API key and no network. Delete `data/tcglife.db` to start over, or use
**Settings → Reset save** to reset the game while keeping the catalogue.

### Double-click build (Windows exe)

Package the whole game as a standalone executable — no Node install needed on the target machine:

```bash
bash scripts/build-exe.sh      # typecheck → vite build → esbuild bundle → SEA inject → brand → release/
```

`release/TCG-Life.exe` is a native desktop window — a WebView2 host that spawns `release/TCG-Life-Server.exe` (the API server as a Node single-executable) and shows the game in its own frame, with the app icon on the taskbar and no browser involved. The window is a normal taskbar citizen (v0.5.26): minimize minimizes, X quits for real and stops the server. The **system tray** icon remains as a convenience — **Open TCG Life** brings a minimized or buried window back, **Quit** ends the app — and launching the exe again while it's minimized restores the window instead of starting a second copy. The release folder carries the built SPA (`dist/`), the SQLite catalog (`data/`), `schema.sql`, the better-sqlite3 native addon, and the WebView2 runtime files; browser profile data lives in `%LOCALAPPDATA%\TCGLife`, so the folder stays clean and movable — the save lives in its `data/`. Launching shows a branded splash (icon, title, version) whose card art breathes and sweeps a gloss highlight while the server boots — the splash pumps on its own thread so boot-time message floods can't starve the animation. Boot progress shows in the splash itself (server → catalog → opening the shop), and boot failures render as a branded panel with the frozen icon and a **View log** shortcut instead of a plain Windows dialog. The server exe still opens a browser when run directly (`TCGLIFE_NO_OPEN=1` opts out).

For a real install, run `npm run build:installer` — it builds the app, stages a factory-fresh payload (no player save inside), and compiles `dist-server/TCG-Life-Setup-<version>.exe` with Inno Setup (per-user, no admin; installs to `%LOCALAPPDATA%\Programs\TCG Life`). The installer adds a Start Menu entry and an optional desktop shortcut, checks for the WebView2 runtime (offering Microsoft's silent bootstrapper if missing), and registers an uninstaller. Uninstalling preserves the save (`app\data`) — interactive uninstalls offer a wipe prompt, silent uninstalls never delete data; reinstalling picks the save back up.

Versions are automated from `package.json`: every build stamps the exe metadata (`scripts/brand-exe.sh`), inlines the version into the packaged server (`--define:__TCGLIFE_VERSION__`, reported in the boot log; dev via tsx shows `vdev`), and names the installer accordingly — bump `version`, run the build, everything tracks it.

The CardDetail **■ Slab Certifier** panel (when you own a graded copy) reproduces the label in miniature — service, grade word, grade number, cert number — and reads out the est. resale from real graded comps (PriceCharting first, then eBay, falling back to the PSA rung of the same number when your service isn't quoted) plus profit/loss against your cost basis. The full-width **COMP LADDER** below shows every graded rung the game has a quote for — each with its est. resale, source, and P/L against your slab's cost, your own rung highlighted. When you own a raw copy too, the 🎯 **Best chase** strip computes the ROI of grading it: each eligible service's fee against the copy's real grade odds (sub-stats included) × current comps, net of the marketplace fee — with the best service's target rung marked on the ladder, or an honest "below just selling it raw" when no service clears the bar. Graded cards render in a **real PSA-style slab** — frosted silver case, red-framed white label across the top (card name and set lines left; card #, grade word, and the big grade number right; barcode + italic PSA logo + cert number along the bottom), and the card floating in a dark well below — everywhere a graded copy appears: Inventory grids and tables, CardDetail's hero (when you own a slab of it), Convention stock, and the Grading screens. Small thumbnails collapse the label to the grade number only. Raw cards stay bare, so slabs read as physically different at a glance.

The exe carries a real app icon (a tilted card over a Pokéball-style ball on navy, generated by `scripts/make-icon.ts` + `scripts/png-to-ico.py`, stamped in with resedit) and Windows version metadata. `CreateDesktopShortcut.cmd` — also shipped in `release/` — drops an installer-free `TCG Life.lnk` on your desktop pointing at the exe; run it once after moving the folder to its final home.

Dev mode needs Node; the packaged exe does not (it *is* Node).

On first launch the server syncs **every Pokémon TCG set** from the official API in the background (shop-priority sets first). You can play immediately; cards and prices appear as each set lands. The sync is checkpointed per set and resumes automatically on restart.

Optional: a free API key from [pokemontcg.io](https://pokemontcg.io) raises the rate limit from 1,000 to 20,000 requests/day — paste it in **Settings** (or set `POKEMONTCG_API_KEY`).

## Data & honesty rules

| What | Source | Labeled |
|---|---|---|
| Card identity, sets, rarities, images | pokemontcg.io API v2 | — |
| USD market price | TCGplayer via pokemontcg.io | **LIVE** (+ retrieval date) |
| EUR prices & sale averages | Cardmarket via pokemontcg.io | shown in price rows |
| Non-NM conditions, pack economics | multipliers on real anchors | **ESTIMATED** |
| Price history | our daily snapshot log (SQLite) | **snapshot log** |

- Card artwork is hot-loaded from the API's official CDN (`images.pokemontcg.io`) — nothing is copied into this repo.
- Sealed-product MSRPs are official Pokémon Center retail; sealed market premiums are not live-synced and are treated as paid cost.
- The simulation (NPC listings, buyer behavior) never invents card values — it derives everything from the synced TCGplayer anchors.

## Architecture

```
server/            Hono API (port 8787) + SQLite (data/tcglife.db)
  services/sync.ts     resumable pokemontcg.io sync (priority sets first) + weekly catalog delta-sync (new sets/cards as they release)
  services/market.ts   price resolution, snapshots, NPC feed, sales engine, game clock
  services/packs.ts    sealed catalog, pull tables from real rarity data, pull roller
src/               React SPA (Vite, port 5199)
  views/               Home, Collection, SetDetail, CardDetail, Market, Packs,
                       PackOpening, Inventory, Wishlist, PullHistory, Settings
```

Game time: the world ticks when you play (state polls every 15s; at most one tick per 20s). NPC listings expire, deals get sniped, your listings sell faster when undercut.
